⏱️ Cơ chế Log Work trên Kanban Board

Chỉ có 1 cách log duy nhất: bấm Timer icon trên card → mở LogWorkModal

🔑 Các icon trên Issue Card

Clock — Logged time (read-only, không edit được)
Timer — Estimate (edit được khi bấm Pencil)
⌛ Timer icon — Quick Log (chỉ hiện khi Edit Mode ON)
✏️ Pencil — Edit card fields (chỉ hiện khi Edit Mode ON)

Fetch lifetimeTotal
Gọi fetchIssueWorklogTotal(issueKey) → GET /issue/{key}/worklog → sum tất cả worklog của issue này (lifetime).
lifetimeTotal = 7200 // 2h đã log từ trước đến nay
3
Rule 1: Lifetime ≤ 8h
(lifetimeTotal + newSeconds) ≤ 8 * 3600
(7200 + 14400) ≤ 28800 → true ✅
4
ADDITIVE: Tạo worklog mới
Gọi addWorklog({ issueKey, timeSpentSeconds: newSeconds, started }) — KHÔNG xoá worklog cũ. Cơ chế cộng dồn.
POST /issue/PROJ-123/worklog { timeSpentSeconds: 14400, started: "2026-05-24T08:30:00.000+0700" }
5
onSuccess() → mutate() board
Đóng modal, refresh toàn bộ board để cập nhật số liệu logged time trên card.

📊 So sánh: Trước đây (Overwrite) vs Bây giờ (Additive)

❌ Trước đây — Overwrite ✅ Bây giờ — Additive
Kịch bản: Sub-task A có 2h ngày hôm nay
User muốn log thêm 4h cho A

// Xoá worklog cũ (2h) deleteWorklog(A, wl_id)

// Tạo mới (4h)
addWorklog({ issueKey: A, timeSpentSeconds: 14400 })

// Kết quả: A = 4h ❌ (mất 2h)
Kịch bản: Sub-task A có 2h ngày hôm nay
User muốn log thêm 4h cho A

// Không xoá gì cả

// Tạo worklog mới (4h)
addWorklog({ issueKey: A, timeSpentSeconds: 14400 })

// Kết quả: A = 2h + 4h = 6h ✅
⚠️ Vấn đề:
  • Mỗi sub-task chỉ có 1 worklog/ngày
  • Log đè lên nhau → mất dữ liệu cũ
  • User phải nhập tổng số, không phải số thêm
 ✅ Lợi ích:
  • Sub-task có thể có nhiều worklog/ngày
  • Cộng dồn → giữ nguyên lịch sử
  • User nhập số muốn thêm, không cần tính tổng

✅ Validation Rules

RuleFormularKhi fail
Lifetime ≤ 8h lifetimeTotal + newSeconds ≤ 8 * 3600 Báo lỗi: "Sub-task PROJ-123 lifetime: đã log 2.0h, còn 6.0h. Không thể log 8h."
Lưu ý: Daily total check (≤ 8h/ngày) được xử lý ở Jira backend + worklog page. Modal chỉ check lifetime để tránh request phức tạp.

🎬 Ví dụ thực tế

Giả sử: Hôm nay (24/05), bạn có:
Sub-taskĐã logDuedateHành động
PROJ-101 (Task A) 2h 28/05 Bấm ⌛ → Date = 28/05 (duedate) → nhập 4h → Log
PROJ-102 (Task B) 1h — Bấm ⌛ → Date = 24/05 (today) → nhập 2h → Log
Kết quả:
- PROJ-101: lifetime = 2h + 4h = 6h (worklog ngày 28/05: 4h)
- PROJ-102: lifetime = 1h + 2h = 3h (worklog ngày 24/05: 2h)
- Cả 2 đều ≤ 8h → ✅

✏️ Pencil Edit Mode — Chỉ edit được Est, không log

!
Khi bấm Pencil
  • Clock icon (logged time) → hiển thị read-only. Không có input, không edit được.
  • Timer icon (Estimate) → hiển thị editable input (type=number). User có thể sửa originalEstimate.
  • ⌛ Quick Log → vẫn hoạt động bình thường (song song với Pencil).
